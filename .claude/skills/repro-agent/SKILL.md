# repro-agent

## Goal

Given `/repro <github-issue-url>`, autonomously reproduce the bug in a running local Plane instance and emit a deterministic Playwright test + evidence so the reproduction replays without you.

## Roles

- **You** = brain. Plan, reason, judge, compile.
- **Stagehand** (localhost:3000) = hands. Translates NL instructions to DOM actions via REST API. Does not plan or judge.
- **Plane** (localhost) = target app. Passive.

## Phases

Execute autonomously via `/loop`: **READ → PLAN → SEED → DRIVE → VERIFY → EMIT**

| Phase | Goal | Writes to disk |
|-------|------|---------------|
| PRE-CHECK | Confirm Stagehand + Plane are reachable. Start one Stagehand session for the entire run. | — |
| READ | Get the issue content via `gh issue view` | — |
| PLAN | Classify the bug, structure preconditions + steps + oracle | `repro-plan.json` |
| SEED | Ensure Plane has the data state the bug requires | — |
| DRIVE | Log in, then execute the reproduction steps via Stagehand | `action-log.json` |
| VERIFY | Screenshot + vision judgment → structured verdict | screenshots |
| EMIT | Generate replay artifacts from the action log | `repro.spec.ts`, `verdict.md` |

## Constraints

- **Disk-first.** Write `repro-plan.json` during PLAN, append `action-log.json` during DRIVE. State survives context loss.
- **One session.** A single Stagehand session spans the entire loop. Start in PRE-CHECK, end in EMIT.
- **Login is step zero.** Every DRIVE begins with authentication. The emitted `repro.spec.ts` must also begin with login.
- **Log every action.** Every Stagehand call (act/observe/extract/navigate) gets an entry in `action-log.json` with the instruction, result, and timestamp.
- **Adapt, don't repeat.** On retry, examine the evidence, reason about what went wrong, and change approach. Never re-run identical failed steps.
- **Max 5 DRIVE→VERIFY cycles.** After that, emit partial evidence with a "could not reproduce" verdict.
- **Verdict is structured.** `{ reproduced: bool, confidence: high|medium|low, reasoning: string, evidenceFile: path }`. Proceed to EMIT only when `reproduced=true AND confidence≥medium`.

## Execution

- Stagehand calls are made by writing small TS scripts that import `lib/stagehand-client.ts` and running them with `npx tsx`.
- Seeding uses Stagehand UI for visual data creation and Plane REST API for fast checks. Decide dynamically per bug.
- `repro.spec.ts` is generated by translating `action-log.json` entries into Playwright API calls. Review and improve the generated selectors.

## Exit conditions

- ✅ Bug reproduced (confidence ≥ medium) → emit artifact bundle
- ❌ 5 retries exhausted → emit partial evidence + failure verdict
- 🚨 Fatal error (Stagehand/Plane down) → exit with error
- 💰 Token budget exceeded → safety exit

## Domain knowledge

See `lib/plane-adapter.ts` for Plane URLs, credentials, workspace/project, nav patterns, API base, and existing seed data.

## Artifact bundle

All output goes to `reproductions/<issue-number>/`:

| File | Purpose |
|------|---------|
| `repro-plan.json` | Structured reproduction plan |
| `action-log.json` | Every browser action taken |
| `repro.spec.ts` | Deterministic Playwright test for replay |
| `evidence/` | Screenshots, video, console logs |
| `verdict.md` | Human-readable judgment |

## Lib reference

| Module | What it provides |
|--------|-----------------|
| `lib/stagehand-client.ts` | `StagehandClient` — `startSession`, `act`, `observe`, `extract`, `navigate`, `screenshot`, `endSession` |
| `lib/plane-adapter.ts` | `PlaneAdapter` — URLs, creds, nav patterns, seed data counts |
| `lib/repro-plan.schema.ts` | Types: `ReproPlan`, `ActionLogEntry`, `Verdict`, `BugClass` |
| `lib/artifact-emitter.ts` | `writePlan`, `appendActionLog`, `writeVerdict`, `generateReproSpec`, `ensureReproDir` |
