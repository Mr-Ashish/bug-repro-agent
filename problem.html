Manual reproduction

  • Read issue, set up environment
  • Click through UI for 15 min
  • Bug already fixed? Time wasted.

With the agent

  • Fixed bugs get NOT_REPRODUCED

  • Maintainers triage from evidence

Design

📝

Issue = plan

Prompt built from issue body. No hardcoded steps. Swap the URL, reproduce a different bug.

👁️

Reproducer, not fixer

Reports what it sees. Never patches code or claims to have resolved anything.

💾

Disk-first

Evidence saved during the run. Crash at step 12? You still have steps 1–11.

🐍

Pure Python

Three scripts, one language. No Node.js, no build step, no TypeScript.
