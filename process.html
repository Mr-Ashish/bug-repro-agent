Phase 5: Run drive.py

Tool Check drive.py config
grep -n 'max_steps\|viewport\|MODEL' scripts/drive.py
→ max_steps=50, viewport 1920x1080, Claude Sonnet 4
↓
Tool Launch agent
python scripts/drive.py \
  --url https://github.com/makeplane/plane/issues/9329 \
  --context reproductions/9329/context.txt

The agent runs in the background. drive.py fetches the issue, builds the prompt from TASK_TEMPLATE + issue body + context, creates the browser-use Agent, and calls agent.run(max_steps=50).

What drive.py does not do
drive.py never sees the bug. It injects the issue text into a generic template, hands it to the browser-use agent, and saves whatever comes back. The agent is the only layer that reads the bug report and decides what to click.
